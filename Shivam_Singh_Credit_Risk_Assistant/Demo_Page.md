# Demo Page Note

The app can be run locally from the source folder.

## Run Instructions
1. Open a terminal in the submission source folder.
2. Run: python app.py
3. Open the browser at http://127.0.0.1:5001/
4. Enter applicant details and the what-if scenario values.
5. Click Generate Assessment.

## Expected Behavior
- The page loads the underwriting form with visible what-if inputs.
- The assessment API returns a JSON response.
- The result shows risk level, recommendation, rationale, fairness audit, a what-if summary, and a simple applicant explanation.
