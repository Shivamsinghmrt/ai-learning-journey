# Acceptance Criteria

1. The user can enter applicant details and receive a risk assessment.
2. The system shows a recommendation and rationale.
3. The system displays what-if input fields for income, debt, and loan amount on the UI.
4. The assessment output includes a visible what-if summary that explains how the scenario changes the debt-to-income burden.
5. The system includes fairness and audit guidance.
6. The system generates a simple applicant explanation letter.
