# Specifications Document

## Functional Requirements
1. The system should accept applicant profile details including income, debt, loan amount, credit score, employment status, and loan purpose.
2. The system should provide a visible what-if scenario section in the UI for income, debt, and loan amount.
3. The system should generate a structured assessment with risk level, recommendation, rationale, key factors, and a what-if summary.
4. The system should include fairness and audit guidance.
5. The system should generate a simple applicant explanation letter.

## Non-Functional Requirements
1. The system should be easy to run locally.
2. The system should be understandable and explainable.
3. The system should be safe and responsible in handling user inputs.
