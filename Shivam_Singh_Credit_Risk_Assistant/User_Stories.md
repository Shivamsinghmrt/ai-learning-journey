# User Stories

1. As a loan reviewer, I want to enter applicant financial details so that I can get a structured risk assessment.
2. As a loan reviewer, I want to simulate what-if changes directly in the UI so that I can understand how risk changes under different scenarios.
3. As a compliance-minded reviewer, I want fairness notes and scenario impact details so that the reasoning remains auditable and responsible.
4. As a business user, I want an applicant-facing explanation letter so that communication is clear and consistent.
