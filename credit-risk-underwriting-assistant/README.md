# AI Credit Risk & Loan Underwriting Assistant

## Objective
Build a decision-support assistant that evaluates a loan applicant profile and produces:
- a structured risk assessment,
- a recommended decision,
- an explanation of the reasoning,
- a fairness audit summary,
- and a simulated what-if analysis.

## SDD Flow
1. Define the problem and scope
2. Write functional requirements
3. Implement the core workflow
4. Add UI and scenario simulation
5. Test key behaviors
6. Refine outputs for explainability and auditability

## Features
- Accept applicant profile and financial details
- Generate a structured risk report with risk level, factors, and recommendation
- Support what-if scenario changes for income, debt, and loan amount
- Include fairness guardrails and audit notes
- Generate an applicant-facing explanation letter
