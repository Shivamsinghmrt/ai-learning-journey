# Day 08 - Agentic AI with Tools and Research Patterns

## Goal

This lesson teaches you how an agent becomes more powerful when it can call tools and collect real information.

## 1. Why tools matter

When a model is just generating text, it is limited by the information available in its context. Tools allow it to reach beyond that by using functions, APIs, or knowledge sources.

## 2. Research scout example

The research scout gathers facts from several queries, then combines them into a single brief. This resembles how a human research assistant would work: gather data, compare findings, and synthesize the result.

## 3. Support triage example

The support agent uses tools to inspect an order record and determine whether a refund is allowed. This is much more practical than giving a generic answer because the response is grounded in data.

## 4. Why this is important

Many real business tasks require both reasoning and factual access. The model can do the reasoning, but the tool provides the facts.

## Learning takeaway

Agents become far more capable when they use tools to interact with the world around them.
