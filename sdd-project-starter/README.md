# SDD Project Starter

This folder is prepared as a simple starting point for the next project you want to build using the learning from this repository.

## What this starter includes
- A simple HTML interface that can be opened in a browser
- A Python backend entry point that can later be connected to OpenAI or other AI services
- A structure that supports Specification-Driven Development (SDD)

## Suggested SDD flow
1. Define the problem statement
2. Write the functional requirements
3. Break the work into modules
4. Build the UI and backend iteratively
5. Test the flow end to end
6. Improve based on feedback
